## Chess opening data

The generated opening database uses data from `lichess-org/chess-openings`.

- Source: https://github.com/lichess-org/chess-openings
- Licence/dedication: Creative Commons CC0 1.0 Universal / public-domain dedication

The dataset is an aggregated collection of chess-opening names. Its upstream project asks users to recognise the curation effort even though the data is released into the public domain.

## Lichess puzzle data

NexoChess incorporates positions from the open lichess.org puzzle database, published under CC0 1.0.

- Source: https://database.lichess.org/#puzzles
- Licence/dedication: Creative Commons CC0 1.0 Universal / public domain
- Upstream format: PuzzleId, FEN, UCI moves, rating, popularity, themes and source-game URL

The first move in each database row is the opponent's setup move. NexoChess applies it before showing the position and treats the following move as the first move of the solution.

NexoChess is an independent project and is not affiliated with, sponsored by or endorsed by lichess.org.

This attribution is presented on the legal Source code and licences page. It is deliberately not repeated inside every puzzle, the main navigation or coach speech bubbles.
