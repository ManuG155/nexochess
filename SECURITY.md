# Security policy

## Supported versions

NexoChess is currently in pre-release development. Security fixes are applied to the latest version available from the `main` branch and to the latest public deployment.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected security vulnerability.

Send a private report to **contact@nexochess.com** with:

- a clear description of the issue;
- the affected URL, route or component;
- reproducible steps or a proof of concept;
- the expected impact;
- any suggested mitigation;
- whether the report contains personal data or credentials.

Do not include real passwords, session cookies, OAuth secrets or personal data belonging to other users. Use a temporary test account whenever possible.

We will acknowledge a valid report as soon as reasonably possible, investigate it, and coordinate a fix before public disclosure.

## Scope

Relevant reports include authentication bypasses, account takeover, exposure of private Archive data, injection vulnerabilities, privilege escalation, server-side request abuse, leaked secrets and unsafe handling of uploaded or imported game data.

General feature requests, visual bugs and translation errors should use the normal GitHub issue templates.
