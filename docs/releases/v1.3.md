# NexoChess v1.3 — Release notes

Release date: 18 August 2026.

NexoChess 1.3 broadens the project from game review into a more complete chess-learning platform and introduces the first major mobile and tablet optimisation pass.

## Highlights

- **Lessons:** a complete playable learning path with 80 guided lessons, realistic positions and coach-led practice.
- **Duel:** play against Stockfish at selectable Elo levels with live move feedback, retry or continue after serious mistakes, Undo/Redo and saved unfinished games.
- **More pedagogical Analysis:** tactical ideas can open as playable engine variations; important tactical and strategic ideas use selective teaching arrows; manual board annotations clear naturally after a tap or click.
- **Mobile and tablet overhaul:** Analysis, Puzzles, Archive, Repertoire, Lessons, Duel and the rest of the main interface now have responsive, touch-friendly layouts, including dedicated mobile review flows.
- **Better training from your own games:** generated puzzles now focus on mistakes, misses and blunders rather than inaccuracies.
- **Project support:** a compact Ko-fi support action has been added to the navigation bar.

## Analysis and review

The review experience is more explanatory and interactive. Tactical concepts in coach comments can be opened as engine-backed playable lines instead of being shown only as notation. Teaching arrows are deliberately selective so they appear for meaningful ideas rather than ordinary moves. Mobile review uses a dedicated layout with the coach commentary above the board, a horizontal move strip and persistent navigation controls.

## Mobile and tablet

NexoChess now adapts its main workflows to phones and tablets instead of simply shrinking the desktop interface. Mobile layouts prioritise the board and the active task, while tablet portrait follows the mobile structure at a larger scale and tablet landscape keeps a compact desktop-style layout where space allows.

## Puzzles

Puzzles generated from analysed games now exclude inaccuracies and focus on positions created by mistakes, misses and blunders. The thematic puzzle catalogue and its existing filtering system remain available.

## Compatibility and infrastructure

The release preserves the existing Cloudflare Workers + Static Assets architecture, D1-backed account/progress data, Better Auth flows, Stockfish 17 analysis, 11-language interface, light/dark themes, CI, CodeQL and production safeguards.

NexoChess remains free and open source under GPL-3.0.

Thanks for using NexoChess and helping improve it.
